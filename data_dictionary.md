# Data Dictionary

This dictionary documents the committed workbooks and Stata-derived variables used by `Hickam Analysis.do`. It is intended for interpretation, audit, and reuse of the public repository data. The companion machine-usable file is `data_dictionary.csv`.

Review status values:

- `verified`: documented directly from workbook headers or Stata recodes.
- `needs_review`: inferred from headers, sparse notes, or duplicated/blank columns and should be checked against study records before reuse.

## Stata Analysis Variables

| Variable | Source | Values / derivation | Review status |
| --- | --- | --- | --- |
| `answer` | Survey vignette response column, renamed from Stata-imported `ConsentThisisanonymousre` | `1 = Vignette 1`; `2 = Vignette 2`; `3 = Vignette 3`; `4 = Vignette 4` | verified |
| `pgy_cat` | Survey training column, renamed from Stata-imported `HowmanyyearshasitbeenPGY` | `1 = Layperson/Allied Health`; `2 = Medical Student`; `3 = PA/DNP`; `4 = PGY1`; `5 = PGY2-3`; `6 = PGY4-5`; `7 = PGY6-10`; `8 = PGY 11-20`; `9 = PGY 21+` | verified |
| `specialty` | Survey specialty column, renamed from Stata-imported `Whatbestdescribesyourareaof` | `1 = Gen IM/Hosp./Family`; `2 = IM subspecialty`; `3 = Emergency`; `4 = Other` | verified |
| `answer_correct` | Derived from `answer` | `1` if `answer == 4`; `0` if `answer` is 1, 2, or 3 | verified |
| `trainee_status_cat` | Derived from `pgy_cat` | `0 = Pre` for medical students; `1 = PGY 0-5` for PGY1 through PGY4-5; `2 = PGY 6+` for PGY6-10 through PGY21+; layperson/allied health and PA/DNP are set missing | verified |
| `model_pr` | Predicted probability from adjusted logistic model | Generated by `predict model_pr, pr` after `logistic answer_correct ib1.specialty ib5.pgy_cat` | verified |
| `manual_case_answer` | Manually simulated count block in the do-file | Counts used for the illustrative `Cases Pie.png`: category counts 22, 24, 35, and 3 | verified |

## Data-Safety Notes

- The repository data are intended to be public/anonymized source data for the article.
- Do not add raw survey exports with respondent identifiers beyond the committed anonymous data.
- Do not add patient-level clinical data or unpublished source documents.
- Do not treat generated outputs as canonical unless they were produced from the current commit.
